## 静的ファイルの軽量化

- 本文・見出し・ボタンにはNoto Sans JPを使用します。Google Fontsから400・600・700のウェイトを読み込み、取得できない場合は端末のゴシック体で表示します。
- ホームのお知らせ欄には、丸みのあるZen Maru Gothicを使用します。通常の文字は400、募集文とラベルは少し太い500で表示します。
- ドットフォントの読み込みは行いません。
- タブのアイコンには64pxの `image/favicon.png` を使用します。SNS共有用の `image/ogp.png` は元のままです。
- ページ背景は無地とし、ホームのタイトル枠に大学の写真と水色のグラデーションを重ねています。
- 最小幅は `css/main.css` の `--site-min-width: 360px` で指定し、それ以下では横スクロールで表示します。
- 反映時はHTML・PHP・CSSに加え、`image/favicon.png` も転送してください。

アイコンの元ファイルを変更した場合は、Python環境に `Pillow` を
インストールし、`python scripts/optimize_assets.py` で再生成します。
この処理は開発時だけ必要で、サーバー側の追加ライブラリは不要です。

## セキュリティ設定

- ログインを含む更新系フォームにCSRF検証を適用しています。ログインは15分間に同一アカウント10回、接続元IP50回までです。制限時はHTTP 429と `Retry-After` を返します。
- セッションはCookieだけを使い、未発行のIDを拒否します。Cookieは `Secure` / `HttpOnly` / `SameSite=Lax` です。HTTPS終端がCaddyでも、PHPが受け取ったHTTPヘッダーを信頼してSecureを外すことはありません。
- HTTPでの**ローカル開発時だけ**、PHPの環境変数に `MUC_SESSION_SECURE=0` を設定してください。本番はHTTPSを使用し、この変数を0にしないでください。
- 管理者セッションは無操作30分またはログイン後8時間で失効します。アカウントの削除・パスワード更新時にも失効します。この変更以前のログイン状態は再ログインが必要です。
- `MUC_DATABASE_PATH` に、公開ディレクトリ外に置いた既存SQLiteファイルの絶対パスを指定できます。存在しないパスでは接続を止めます。DBの移動や既存ファイルの削除はコードから自動実行しません。
- 以前Gitで追跡していた `backup/storage/muc.sqlite` は追跡対象から外しましたが、過去履歴には残ります。リポジトリを共有したことがある場合は管理者パスワードを変更してください。

### サーバー側で反映する設定

**PHPだけでは `storage/muc.sqlite` やバックアップの直接ダウンロードを防げません。**
`Caddyfile.security` を外側のCaddyのsite blockへimportし、`nginx-security.conf`
を内側のnginxのserver blockへincludeしてください。ファイルをWeb領域へ置くだけでは有効になりません。
nginxの正規表現locationは汎用PHPのlocationより前へ置き、同じlocationが既にあれば統合します。
反映前に `caddy validate --config <本番Caddyfile>` と `nginx -t` で既存設定との整合を確認します。

これらの設定はDB・バックアップ・内部コード・隠しファイルを404で拒否し、
アップロード領域では許可した媒体だけを静的配信します。PHP実行を許可しません。
本番では外側のCaddyを経由せずにnginxへ接続できないネットワーク設定も必要です。
DBを移動する場合は停止中にWALを含めた整合性のあるバックアップを取り、
新しいパスで動作確認したうえで、公開領域に残した旧DBとバックアップを撤去してください。

このリポジトリでのテストは一時サイトで行います。本番設定の読み込み・再読み込みや、
公開URLからのDB取得可否は別途確認が必要です。詳しい範囲は `docs/security-review.md` に記載しています。

### 管理画面でのパスワード変更

ログイン後、管理画面の「パスワードを変更」を開き、現在のパスワードと、
新しいパスワードを確認用も含めて2回入力します。新しいパスワードは12文字以上・
UTF-8で72バイト以内（半角英数字なら72文字、日本語なら目安24文字）で、現在とは異なるものを指定します。
更新後はこの端末のログインを維持し、他の端末のセッションは次の認証確認時に失効します。
変更の試行はアカウントごとに15分間10回までで、ログインと共通のIP枠も適用します。
入力したパスワードは再表示せず、DBにはハッシュのみを保存します。
この機能を本番へ反映した後、実際にフォームから更新してください。コードの反映だけでは既存パスワードは変更されません。

### 回帰確認

```text
php tests/security.php
python tests/security_http.py
```

PHP 8.1以上（pdo_sqlite・mbstring）とPython 3を使用します。
HTTPテストは一時ディレクトリにサイトとテスト専用DBを作成し、実データを変更しません。
`php` がPATHにない場合は、`PHP_BINARY` に実行ファイルのパスを設定してください。
