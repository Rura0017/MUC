## 投稿URL

投稿の正規URLは `/pages/post.php?id={id}` です。`id` は表示する投稿を
識別するために必要な値であり、不要なパラメーターではありません。

`Caddyfile.post-routes` は、旧形式の `/pages/posts/{id}` を正規URLへ
転送したい場合だけ、外側のCaddyの site block 内（`reverse_proxy` より前）へ
追加します。このファイルをWeb公開ディレクトリへ転送するだけでは、
Caddyの設定としては反映されません。

## 本番反映時の注意

- 初回アクセス時に既存の `posts` へ投稿区分を追加し、従来の投稿はすべて通常投稿として保持します。
- 従来本文は `plain` のまま保持し、新規本文だけをQuill 2.0.3の構造化形式で保存します。
- HTMLに固定されていた4企画は初回だけ企画データへ移行されます。以後、管理画面で削除しても再作成されません。
- 反映前に `storage/muc.sqlite` をバックアップしてください。
- 添付を使う場合は、PHPから `image/uploads` へ書き込める権限が必要です。
- リッチエディタ本体はバージョンを固定してCDNから読み込みます。読み込めない場合もプレーンテキスト欄で投稿できます。
